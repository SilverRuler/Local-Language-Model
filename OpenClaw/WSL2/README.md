```
  OpenClaw의 bind: "lan" 은 loopback(127.0.0.1)을 UI 접근에서 의도적으로 제한하는 모드입니다. curl로는 TCP 연결이 되지만, 브라우저로 localhost 또는 127.0.0.1로 접속하면
  OpenClaw가 request를 거부하거나 API 인증 단에서 막습니다.
  ──────
  ## 정리

   접근 방법                                              | TCP 연결                                               | 브라우저 UI
  --------------------------------------------------------|--------------------------------------------------------|-------------------------------------------------------
   localhost:18789                                        | ✅ (0.0.0.0 바인딩이라 연결 됨)                        | ❌ bind: lan 때문에 차단
   127.0.0.1:18789                                        | ✅                                                     | ❌ 동일
   10.8.0.10:18789 (LAN IP)                               | ✅                                                     | ✅
   oc.silverruler.xyz → rinetd → 18789                    | ✅                                                     | ✅
  ──────
  ## 블로그에 쓸 설명

  │ OpenClaw의 bind: "lan" 설정은 로컬 loopback(127.0.0.1)에서의 대시보드 UI 접근을 막는다.
  │ 서버 자체에서 curl로 HTTP 응답을 받을 수 있어도, 브라우저로 localhost:18789가 안 되는 이유는 이 설정 때문.
  │ LAN IP(10.8.0.x) 또는 외부 도메인으로 접속해야 정상 동작한다.

  로컬에서 접속하고 싶으면 openclaw.json에서:

    "gateway": {
      "bind": "all"   // 또는 "localhost"
    }

  로 바꾸면 됩니다.
```
